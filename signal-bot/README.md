# Signal-бот черги

Бот слухає **чат-джерело**, шукає в повідомленнях ключові слова і пересилає
знайдені повідомлення в **чат черги**. Кожне переслане повідомлення адресується
(@-згадкою) наступному користувачу з черги, по колу: 1 → 2 → 3 → 1 → …

```
Чат-джерело                         Чат черги
"Був приліт на Лісовій"   ──►   📨 Нове повідомлення
                                 Від: Тарас
                                 Ключові слова: приліт

                                 Був приліт на Лісовій

                                 👉 Відповідальний: @Олена
```

Аналіз повідомлення: знайдені ключові слова, телефони, посилання, кількість вкладень.

## Як працює

Бот — один Python-файл (`bot.py`, лише стандартна бібліотека) поверх
[signal-cli-rest-api](https://github.com/bbernhard/signal-cli-rest-api).
Черга та позиція зберігаються в `state.json`, тому переживають перезапуск.

## Встановлення

1. Потрібен окремий номер телефону для бота.
2. Запустіть API:
   ```bash
   docker compose up -d signal-api
   ```
3. Прив'яжіть номер як додатковий пристрій: відкрийте
   `http://localhost:8080/v1/qrcodelink?device_name=queue-bot` і проскануйте QR
   у Signal на телефоні (Налаштування → Пов'язані пристрої).
   Або зареєструйте номер напряму — див. документацію signal-cli-rest-api.
4. Додайте бота в обидва чати (джерело і черга).
5. Створіть конфіг і дізнайтесь id груп:
   ```bash
   cp config.example.json config.json   # вкажіть bot_number
   python3 bot.py groups                 # покаже id усіх груп бота
   ```
   Впишіть `id` груп у `source_group` і `queue_group`, задайте `keywords`.
6. Запустіть бота:
   ```bash
   docker compose up -d bot      # або: python3 bot.py run
   ```

## Налаштування (`config.json`)

| Поле | Опис |
|---|---|
| `api_url` | адреса signal-cli-rest-api |
| `bot_number` | номер бота, `+380…` |
| `source_group` | id групи, яку слухає бот |
| `queue_group` | id групи, куди пересилаються повідомлення і де керують чергою |
| `keywords` | список ключових слів |
| `case_sensitive` | враховувати регістр (за замовч. `false`) |
| `whole_word` | шукати лише цілі слова. За замовч. `false` — шукається підрядок, тобто «тривог» знайде і «тривога», і «тривоги» |
| `admins` | номери, яким дозволено `/add`, `/remove`, `/skip`, `/clear`. Порожній список — дозволено всім |
| `state_file` | файл для збереження черги |

Основні поля можна задати й змінними середовища: `SIGNAL_API_URL`, `BOT_NUMBER`,
`SOURCE_GROUP`, `QUEUE_GROUP`, `KEYWORDS` (через кому), `ADMINS` (через кому), `STATE_FILE`.

## Команди (пишуться в чаті черги)

| Команда | Дія |
|---|---|
| `/add @Олена @Петро` | додати користувачів у чергу (згадкою або номером `+380…`) |
| `/remove @Петро` | прибрати з черги |
| `/join` / `/leave` | додати / прибрати себе |
| `/queue` | показати чергу в порядку отримання |
| `/next` | хто отримає наступне повідомлення |
| `/skip` | пропустити поточного |
| `/clear` | очистити чергу |
| `/help` | довідка |
