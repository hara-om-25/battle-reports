# Signal-бот реакцій

Бот слухає повідомлення акаунта Signal і, якщо в тексті трапляється ключове слово,
ставить на повідомлення реакцію-емодзі та грає звук на цьому ПК (Windows).

Від `signal-bot/` відрізняється призначенням: той пересилає повідомлення в чат черги,
а цей лише ставить реакцію і подає звуковий сигнал.

## Що робить

| Слово  | Реакція | Де працює                          |
|--------|---------|------------------------------------|
| `ждун` | ➕      | чати з `ONLY_CHATS` (порожньо = усі) |
| `бпла` | ➕      | чати з `ONLY_CHATS` (порожньо = усі) |
| `тест` | 👍      | усі чати (`ALL_CHATS_WORDS`)       |

- Слово шукається всередині тексту, регістр не враховується. Латинські «двійники» літер
  (`a`, `e`, `o`, `p`, `c`, `x`, `y`, `i`, `k`, `m`, `t`, `h`) теж розпізнаються.
  Тому `тест` спрацює і на «протестувати».
- Реагує на вхідні й на власні повідомлення (`REACT_TO_OWN = True`).
- Повідомлення, отримані до запуску бота, ігноруються (`START_MS`).
- Звук: гудки (`BEEPS_BEFORE`), далі озвучка «З'явився ждун» (`SPEECH_REPEATS` разів).
  Гучність перед сигналом піднімається до максимуму (`FORCE_MAX_VOLUME`).
  Звук однаковий для всіх слів і грає в окремому потоці.
- ID групи для `ONLY_CHATS` видно в консолі в рядку `[збіг] ... | чат: <ID>`.

## Встановлення

1. Java 25 (Eclipse Adoptium) і signal-cli 0.14.8 у `C:\signal-cli`.
2. Прив'язати signal-cli як додатковий пристрій:
   `signal-cli link -n "ReactionBot"` → у телефоні: Signal → Налаштування → Прив'язані пристрої.
3. Бібліотеки: `python -m pip install gTTS pycaw comtypes`
4. Скопіювати файли цієї папки в `C:\signal-cli`.
5. Створити `C:\signal-cli\config.json` зі своїм номером (зразок — `config.example.json`):
   ```json
   {
       "account": "+380XXXXXXXXX"
   }
   ```
   Цей файл у git не потрапляє. Замість нього можна задати змінну середовища `SIGNAL_ACCOUNT`.

Файл `zhdun_speech.mp3` створюється поруч зі скриптом під час першого запуску (потрібен інтернет).
Якщо змінити `SPEECH_TEXT`, цей файл треба видалити, щоб озвучка створилася заново.

## Файли

| Файл                  | Призначення |
|-----------------------|-------------|
| `signal_reaction_bot.py` | сам бот |
| `start_bot.bat`       | прихований запуск через `pythonw` (для автозапуску: ярлик у `shell:startup`) |
| `start_bot_debug.bat` | видимий запуск з `pause`, щоб бачити помилки |
| `stop_bot.bat`        | зупинка: вбиває `pythonw.exe` і `java.exe` |
| `config.example.json` | зразок `config.json` з номером акаунта |

## Відомі пастки

- signal-cli 0.14.8 потребує Java 25, а за замовчуванням береться Java 21. Тому `JAVA_HOME`
  задано прямо в `.bat`: подвійний клік не бачить змінних, створених через `setx`, до перезаходу.
- При виході треба вбивати все дерево процесів (`taskkill /F /T`), інакше `java` лишається
  і блокує акаунт. Скрипт робить це сам у `finally`.
- Під `pythonw` помилок не видно — для діагностики запускайте `start_bot_debug.bat`.
- Кирилиця в `.bat` у cmd може показуватись ієрогліфами; на роботу не впливає
  (можна додати `chcp 65001` на початок файлу).
- Реакція має бути справжнім емодзі (➕), а не символом `+`.
- `stop_bot.bat` вбиває **всі** `java.exe` і `pythonw.exe` на ПК, а не лише бота.
